KOORA UNO — SINGLE-FILE WEB GAME

1. Extract index.html from this ZIP.
2. Open index.html in a desktop browser for solo/offline local play.
3. For iPhone, upload index.html to a GitHub repository, deploy the repository to Vercel as a static site, and open the Vercel URL in Safari.
4. To enable online rooms, create a Firebase web app, enable Anonymous Authentication and Realtime Database, and enter your Firebase web config into FIREBASE_CONFIG in index.html.
5. ChatGPT's HTML file preview may show "Couldn't load this file". That does not necessarily mean the code is broken; download the ZIP instead.

Online multiplayer requires Firebase configuration. External card images may need internet.
